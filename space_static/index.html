Paste a question and long text (search results, documents, notes). Chopper keeps only the exact quotes that answer it, typically 2–5% of the text, and ranks the passages, in one pass of a small open model. It runs in your browser: nothing is sent to a server.

Model: the small chopper (mmBERT-small, 0.14B), int8 embeddings and fp16 matrices (same chops as the PyTorch model on 23 of 24 test rows). Relevance = mean p(KEEP) of a passage's 16 most likely tokens: the chopper used as a reranker. On a GPU the Python package takes about 0.1 s for 16 passages; here it runs on your CPU. 8 languages (en, de, fr, es, pt, pl, zh, ja). This in-browser demo uses the smaller model; the recommended base (0.31B) runs with pip install chopper-rag. Polish version with the Polish small-pl model.
