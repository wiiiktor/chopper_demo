Chopper 0.3B close to Opus 5.5 in cutting out the best pieces

Chops are pieces cut out of the original text snippets retrieved from a database or a long conversation: exact quotes, never rewritten. The chopper (mmBERT, 0.31B) makes them; for comparison, Claude Opus 5.5 makes them too, also forced to quote directly.

One database retrieval per question, even at 4 hops

Every result on this page uses a single retrieval: each question gets its 20 snippets once, the chopper cuts them once, and Qwen3-14B answers once. There are no follow-up searches and no second rounds, so a 4-hop question has to be chained from one cut.

mmBERT is 32,000 times smaller

each dot = 0.31B, the size of the chopper
Multi-hop chopper (mmBERT): 1 dot, 0.31B Claude Opus 5.5: a 32 × 32 × 32 cube, ~32,000 dots (~10,000B, a rough estimate; the size is not published)

Against other context compressors

Same 400 questions, same 20 snippets, same Qwen3-14B prompt; each compressor cuts the snippets once. LLMLingua-2 drops tokens without looking at the question; Provence reads the question but prunes each snippet on its own. To be fair to them: the chopper was trained on MuSiQue's train split (this test uses its dev split) and on other multi-hop data, while both were trained for general single-passage use.

Use it

pip install chopper-rag          # or "chopper-rag[langchain]", [llama-index], [haystack]

from chopper_rag import Chopper
chopper = Chopper.from_pretrained(variant="base")   # "small", "base-pl", "small-pl"
result = chopper.run(question, passages)            # result.chops: exact quotes; result.decision: ANSWER / SEARCH
